# ⚡ GUIA RÁPIDO DE INSTALAÇÃO - CELULAR

## 🚀 A forma MAIS FÁCIL de instalar em 3 passos

### Passo 1: Abra o Replit
- Acesse: https://replit.com
- Clique em **"Create Repl"**
- Selecione **"Import from GitHub"**

### Passo 2: Importe o Projeto
- Cole este link:
```
https://github.com/aamerzine-pixel/whatsapp-bot-grupo-v2
```
- Clique em **"Import Repl"**

### Passo 3: Rode o Bot
No terminal do Replit, execute:
```bash
npm install
npm start
```

## 📱 Como Usar no Seu Celular

1. **Veja o QR Code** que aparecerá na tela do Replit
2. **Abra WhatsApp** no seu celular
3. **Vá em:** Configurações → Aparelhos Conectados
4. **Escaneie o QR Code** com sua câmera
5. **Pronto!** Seu bot está online!

## 💬 Testando o Bot

Crie um grupo no WhatsApp e:

1. **Convide o bot para o grupo** (ele entrará como sua conta)
2. **Digite comandos:**
   - `!ajuda` - Ver todos os comandos
   - `!regras` - Ver regras
   - `!jogos` - Ver jogos
   - `!jogo piada` - Contar uma piada

## 🎮 Comandos Principais

```

!jogos               → Lista todos os jogos

!jogo trivia         → Pergunta trivia
!jogo piada          → Pede uma piada
!jogo charada        → Charada
!jogo pedrapapeltesoura → Jogo de jokenpo
!ajuda               → Mostra esta mensagem
```

## 🐛 Problemas Comuns?

**Bot não conecta:**
- Verifique sua conexão internet
- Escaneie o QR Code novamente

**Comandos não funcionam:**
- Use `!` antes do comando
- Certifique-se que está em um GRUPO

**Bot saiu do ar:**
- Mantenha a aba do Replit aberta
- Não feche o navegador
